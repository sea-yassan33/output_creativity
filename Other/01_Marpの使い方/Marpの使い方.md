# Marpについて
- MarpはMarkdown でスライドを作れるツール

## VSCODE拡張
https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode

## Cloud_Codeプロンプト例

```
「ヘッドレスCMS」についての初めて学習する向けのドキュメントを「docs/」配下に作成してください。
また作成したドキュメントを基にMarp形式のスライド（headress_cms_slides.md）に変換し、「docs/」配下に作成してください。
テーマは default、16:9お願いします。
今回はソースコードの作成は不要です。スライド（slides.md）のみ作成し、「docs/」配下に設置してください。
```
